# Current architecture

Expo/React Native mobile and responsive web share the existing Express/MongoDB/Socket.IO API. Native Android Telecom supplies observed phone events when configured as the default dialer. Business outcomes are separate and survive offline retry. Server reservations protect sequential and manual business calling.

Authorized existing audio attachments use encrypted private storage. Universal SIM capture and live audio require supported integrations.
